# Day 20 of My Challenge — AI Face Puzzle Game


A fun browser-based puzzle game where your photo turns into an interactive jigsaw puzzle. The game captures a face using the webcam, splits the image into puzzle pieces, and lets you solve it with drag-and-drop controls.

## Features

- Webcam photo capture
- 3×3, 4×4, and 5×5 puzzle modes
- Drag-and-drop and touch support
- Live timer and move counter
- Correct piece tracking
- Win detection with results screen
- Leaderboard saved in localStorage
- Responsive design for desktop and mobile

## Tech Stack

- HTML
- CSS
- JavaScript
- Canvas API
- MediaDevices API
- LocalStorage

## What I Learned

This project helped me practice browser camera handling, image processing, puzzle logic, interactive UI design, and state management in vanilla JavaScript.

## Run the Project

Open the HTML file in a modern browser, allow camera access, capture your photo, choose a difficulty level, and start playing.
