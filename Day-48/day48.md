# Compare & Decide Builder

## Overview

Compare & Decide Builder is a premium single-file HTML application that helps users make informed decisions by comparing multiple options using verified data and customizable evaluation criteria.

Instead of relying on opinions, the application allows users to assign importance (weights) to different criteria and instantly see how rankings change.

---

## Features

* Interactive decision questionnaire
* Adjustable criteria weights
* Live ranking updates
* Professional responsive interface
* Sources panel with citations
* Research transparency section
* Loading and empty states
* Graceful error handling
* No external libraries
* Pure HTML, CSS, and JavaScript
