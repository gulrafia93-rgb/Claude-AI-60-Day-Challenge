# Day 27 – Prior Authorization Story Simulator |  ABTalks 60-Day AI Challenge 

## Project Overview

Developed an interactive story-based web application that explains the Prior Authorization (PA) process through conversations and guided decision-making.

## Features

- Interactive Healthcare Story
- 8 Guided Story Scenes
- Chat-Based User Interface
- Branching Decisions
- Progress Bar
- Educational Explanations
- Responsive Modern Design
- Beginner-Friendly Healthcare Concepts

## Technologies Used

- HTML
- Tailwind CSS
- Vanilla JavaScript

## Key Learning

> Storytelling makes complex healthcare workflows easier to understand by combining real-world scenarios with interactive conversations.

## Outcome

Built a complete educational web application that teaches the Prior Authorization process using conversational storytelling and interactive user choices.
