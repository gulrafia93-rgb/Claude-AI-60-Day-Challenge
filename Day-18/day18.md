# Day 18 – Brain Dump Action Planner (Claude Skill)

## 🚀 Overview

This project is part of the **ABTalks 60-Day AI Challenge (Day 18)** where I built a **Claude Custom Skill** called *brain-dump-action-planner*.

The main idea behind this skill is to solve a common problem: people often have scattered thoughts, messy meeting notes, brainstorming ideas, or unstructured project discussions that are hard to convert into clear action steps.

This skill acts like a smart productivity system that takes raw, unorganized information and automatically transforms it into a structured and useful format. Instead of manually sorting tasks, priorities, and ideas, the AI does it in seconds and produces a clean project dashboard.

It is especially useful for students, developers, and SOC Analysts who deal with large amounts of information and need quick clarity for decision-making and execution.

---

##  Skill Name

brain-dump-action-planner

---

##  Purpose

Convert unstructured notes into clear, actionable plans with priorities, risks, and next steps.

---

##  Features

* Executive summary generation
* Action items extraction
* Risk & blocker identification
* Open questions tracking
* Prioritized task planning

---


## Key Learning

This project shows how AI can be used to build reusable systems that improve productivity by converting chaos into clarity and helping in faster decision-making.
