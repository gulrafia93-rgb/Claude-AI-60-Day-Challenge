

## **Day 9 –  NutriScope v2.0 #60DaysOfAI Challenge** ##

NutriScope v2.0 is an AI-powered Nutrition Analytics platform that helps users track calories, macros, micronutrients, meal plans, and health insights through an intuitive SaaS-style interface.

##  Features
- Personalized Biometric Profiles
- Meal Logging & Nutrition Tracking
- Real-Time Macro & Micronutrient Analytics
- Interactive Chart.js Dashboards
- CSV Import & Export
- AI-Powered 2-Day Meal Planner
- Health Risk Analysis & Recommendations

##  Tech Stack
HTML • CSS • JavaScript • Tailwind CSS • Chart.js

##  Key Learning
Built using an iterative AI development approach—starting with an MVP and progressively adding advanced features through prompt engineering and AI-assisted development.
