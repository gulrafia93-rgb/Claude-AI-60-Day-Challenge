# Day 34 – Marketing Detective | ABTalks 60-Day Claude Challenge  


## 📌 Project Overview

Marketing Detective is a detective-style interactive web application that teaches marketing analytics through investigation and discovery.

Players become a marketing detective, analyze campaign evidence, organize clues, identify the primary marketing mistake, and receive a detailed learning report with expert recommendations.

---

## ✨ Features

- Premium Dark Detective UI
- Multiple Color Themes
- Randomized Marketing Cases
- Interactive Investigation Board
- Drag-and-Drop Evidence Cards
- Campaign Performance Analysis
- Marketing Metrics Dashboard
- Case Solving Challenge
- Learning Report
- Responsive Design
- Replay with New Cases

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
- React (CDN)
- Babel

---

## 📚 What I Learned

- Evidence-based marketing analysis
- Campaign performance evaluation
- Understanding customer behavior
- Identifying marketing mistakes
- Improving decision-making through analytics
- Building interactive educational web applications

---

## 🚀 Outcome

This project helped me understand that successful marketing is driven by data, customer insights, and continuous analysis rather than assumptions. It also improved my frontend development skills by building an engaging, interactive learning experience.
