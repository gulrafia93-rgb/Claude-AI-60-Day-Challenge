# Day 32 – Think Like a Marketing Strategist | 60DayClaudeChallenge

## Overview
Built an interactive **Marketing Strategy Simulator** using React, HTML, CSS, and JavaScript.

The application teaches beginners how marketers think by focusing on audience research, platform selection, content strategy, and business growth through an interactive learning experience.

## Features
- Business, Personal Brand & Random Client modes
- Audience analysis
- Platform selection
- Content pillar planning
- 30-day marketing roadmap
- Growth report
- Reusable Claude prompts
- Responsive dark-themed UI

## Technologies Used
- HTML
- CSS
- JavaScript
- React (CDN)
- Babel

## Key Learning
This project helped me understand that effective marketing starts with understanding the audience, selecting the right platforms, creating valuable content pillars, and building a long-term growth strategy.
