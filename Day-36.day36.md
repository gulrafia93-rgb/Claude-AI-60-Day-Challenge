# 🧠 Day 36 – Cognitive Pattern Explorer | ABTalks 60-Day Claude Challenge


## 📌 Project Overview

Cognitive Pattern Explorer is a psychology-inspired educational web application that encourages users to reflect on their thinking and decision-making patterns through interactive activities.

The experience focuses on exploration rather than evaluation, providing personalized insights in a calm and engaging environment.

---

## 🚀 Features

- 🌿 Calm Mode & Stress Mode
- 🧠 Interactive thinking scenarios
- 🎯 Drag-and-drop priority selection
- 🗺️ Thinking timeline mapping
- 📊 Reflection Journal
- 📈 Thinking tendency breakdown
- 📱 Responsive Design
- ⚡ Works completely offline
- 🎨 Modern UI with smooth animations

---

## 🛠 Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

---

## 📚 What I Learned

- Different people approach decisions in different ways.
- Interactive learning creates a more engaging educational experience.
- Drag-and-drop interactions improve user participation.
- Reflection-based applications can teach concepts without making clinical judgments.
- Building responsive offline applications using only HTML, CSS, and JavaScript.
