# Day 26 – Prior Authorization Workflow Simulator | ABTalks 60-Day AI Challenges

## Project Overview

Built a single-page interactive simulator that demonstrates the Prior Authorization (PA) workflow used in the US healthcare system.

## Features

* Patient, Provider, and Payer workflow lanes
* Drag-and-drop interactions
* Multiple patient scenarios
* Prior Authorization document collection
* Approval, Pend, Denial, Appeal, and Peer-to-Peer Review
* Progress Tracker
* Days Elapsed Counter
* Efficiency Score
* Workflow Summary
* Responsive UI

## Technologies Used

* HTML
* CSS
* Vanilla JavaScript

## Key Learning

> Interactive simulations make complex healthcare workflows easier to understand by combining visual storytelling with user interaction.

## Outcome

Developed a complete browser-based workflow simulator that demonstrates healthcare operations, workflow management, and business process visualization without using any backend or external libraries.
