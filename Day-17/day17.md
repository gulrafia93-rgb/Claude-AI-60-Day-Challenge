
# Day 17 - AI Vehicle Cost & Fuel Analysis Dashboard

An AI-powered analytics project that transforms raw vehicle CSV data into an interactive, business-ready dashboard with insights on cost, fuel efficiency, emissions, and performance trends.

---

##  Overview

This project uses AI-driven analysis to process vehicle datasets and generate a complete HTML dashboard. It helps in understanding:

* Vehicle running costs
* Fuel efficiency comparisons
* CO₂ emissions impact
* Maintenance expenses
* Age-based performance trends

The output is a fully responsive, modern dashboard with SVG-based visualizations.

---

##  Features

*  Fuel Cost per KM analysis
*  CO₂ emission comparison across fuels
*  Maintenance cost breakdown
*  Vehicle age-based performance buckets
*  Fuel type comparison (Petrol, Diesel, CNG, EV, E85)
*  Interactive SVG charts (bar, line, doughnut, gauge)
*  E85 cost-benefit analysis
*  Fully responsive UI (mobile + desktop)

---

##  Key Metrics Calculated

* Avg Cost per KM
* Avg CO₂ per KM
* Avg Maintenance per KM
* Refuel/Recharge time
* Age bucket analysis (New / Mid-life / Aged / Old)
* E85 savings, penalty & break-even price
* Monthly vehicle cost estimation


---

##  Purpose

This project demonstrates how AI can be used in real-world data analytics to:

* Convert raw CSV into insights
* Build automated dashboards
* Support business decision-making
* Visualize complex datasets simply
