# 🤖 Autonomous Agent Studio

**Autonomous Agent Studio** is a single-page AI application designed to build, visualize, and execute autonomous multi-agent workflows.

Instead of relying on a single AI prompt, the system coordinates multiple specialized agents that collaborate through an iterative execution loop, continuously evaluating and improving results until predefined success criteria are met.

## ✨ Features

* 🤖 Multi-agent orchestration
* 📋 Planner, Executor, Evaluator, Critic, Improver, Memory Manager, Safety Monitor & Final Reviewer
* 🔄 Iterative execution with configurable stopping conditions
* 📊 Live workflow visualization
* 🧠 Persistent memory management
* 📈 Evaluation reports and improvement tracking
* 📝 Activity logs and execution history
* 🎯 Custom success criteria
* 💾 Session save/load support
* 📤 Export workflow results
* 📱 Fully responsive interface
* 🌙 Dark mode with modern UI

## 🛠️ Technologies

* HTML5
* CSS3
* Vanilla JavaScript
* Anthropic Messages API

## 🎯 Purpose

The objective of this project is to demonstrate how multiple AI agents can collaborate in a structured workflow to automate complex reasoning and decision-making tasks through continuous planning, execution, evaluation, and improvement.
