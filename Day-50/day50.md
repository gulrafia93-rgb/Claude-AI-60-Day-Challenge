# 🛡️ Defend Your Experience

An AI-powered interview preparation application that helps users confidently defend every claim they make about themselves.

Unlike traditional resume review tools, **Defend Your Experience** extracts meaningful claims from resumes, portfolios, LinkedIn profiles, project documentation, research papers, and other professional documents, then challenges users with personalized interview questions generated specifically from their own experience.

## ✨ Features

* 📄 Drag-and-drop document uploads
* 🤖 AI-powered claim extraction
* 🎯 Personalized adaptive interview simulation
* 💬 Dynamic follow-up questioning
* 📊 Real-time confidence and communication analysis
* ⚠️ Weak claim detection
* 📈 Interactive progress dashboard
* 🎯 Multiple interview modes
* 💾 Local storage and session history
* 📤 Exportable Defense Reports
* 📱 Fully responsive design
* 🌙 Dark/Light mode support
* ⚡ Smooth animations and premium UI

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript (Vanilla)
* Anthropic Messages API

## 🎯 Purpose

The goal of this project is **not** to improve a resume.

Its purpose is to help users confidently defend every statement they make about themselves during interviews by identifying weak claims, asking intelligent follow-up questions, and providing actionable feedback.
