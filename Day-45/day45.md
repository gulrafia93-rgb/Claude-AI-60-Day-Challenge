# 🧠 AI Decision Strategist

An AI-powered decision-making assistant that guides users through a structured 4-question interview and generates a beautiful interactive Decision Report.

## ✨ Features

* Guided 4-step interview
* Decision Matrix (7 evaluation criteria)
* Assumption & Cognitive Bias Analysis
* Option Comparison Cards
* Premortem Failure Analysis
* 7-Day Decision Test Plan
* AI Verdict with reasoning
* Animated progress bars
* Responsive dark-themed dashboard
* Shareable summary cards

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Prompt Engineering
* AI Decision Framework
