# 🚀 Product Discovery & Sprint Planning AI

**Product Discovery & Sprint Planning AI** is an interactive AI-powered application that helps users transform an idea into a well-defined product with a structured implementation roadmap.

The application guides users through an adaptive interview, discovers the right project based on their goals and constraints, and continuously generates planning documents throughout the conversation instead of waiting until the end.

## ✨ Features

* 💡 AI-powered project discovery
* 🎯 Adaptive one-question-at-a-time interview
* 📄 Live Product Requirements Document (PRD)
* 📅 Dynamic sprint planning
* 🗺️ Project roadmap generation
* 👤 User persona creation
* ⚠️ Scope definition and risk analysis
* 📊 Interactive dashboard with live updates
* 📈 Progress tracking and milestones
* 💾 Session persistence
* 📤 Exportable planning documents
* 📱 Responsive modern SaaS UI

## 🛠️ Technologies

* HTML5
* CSS3
* Vanilla JavaScript
* Anthropic Messages API


## 🎯 Purpose

This project is designed to simplify the early stages of software development by helping users validate ideas, define requirements, organize priorities, and create an actionable sprint plan with AI assistance.
