Workflow summary

This pipeline moves through Foundation → Frontend → Backend → Full-Stack Integration → Testing → Deployment → Portfolio → Job Applications. Each stage builds the evidence the next one needs: the flagship project scoped in Stage 1 becomes the frontend built in Stage 2, the API in Stage 3, the working app in Stage 4, and the headline case study in Stage 7. Realistic pace is 3–5 months at 15–20 focused hours/week, faster with prior JS experience.

Recommended AI stack

  • Claude / ChatGPT — reasoning, code review, architecture, writing
  • GitHub Copilot or Cursor — in-editor autocomplete and refactors
  • v0.dev / Claude Artifacts — fast UI scaffolding
  • Postman + AI test generation — API design and verification
  • Vercel + Render/Railway + MongoDB Atlas — deployment stack
